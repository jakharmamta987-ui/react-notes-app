# 📝 React Notes App

A modern Notes App built using React.

## 🚀 Features

- Add Notes
- Edit Notes
- Delete Notes
- Search Notes
- Complete / Undo Notes
- Filter Notes (All / Completed / Pending)
- Notes Counter
- Timestamp for Notes
- LocalStorage Persistence
- Responsive UI

---

## 🛠 Tech Used

- React
- JavaScript
- CSS
- Vite
